# Brainiac Marketing Agency website

Live site: https://brainiacmarketingagency.com

The website files are in the root of this repository, so GitHub Pages can serve them directly.

## Editing the site

The pages are plain HTML files. The design is in `styles.css`, and the menu, WhatsApp button, portfolio filters and contact form are in `site.js`.

## Before launch

- Replace the placeholder testimonials with genuine, client-approved quotes.
- Replace or add to the concept projects once real client work is available.
- Confirm the proposed package prices on the Packages page.
- To receive contact-form submissions by email, set `formEndpoint` in `site.js` (for example a Formspree form URL).
